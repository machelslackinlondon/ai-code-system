# Assessment Alignment

Use as a review/audit checklist, not a default execution file.

- Problem-solving: approach, constraints, risks, options
- AI fluency: clear prompts, validate output, iterate/refine
- Code quality: readable, tested, explicit errors, assumptions
- Communication: why, validation, debugging, trade-offs
- Delivery: brief plan, continuous validation, working increments

## Guardrails

Never: accept unread code, skip validation, hide failures, assume AI is correct, over-engineer before validating.

Always: validate early, communicate clearly, think before prompting, sanity-check suggestions, iterate with purpose.

If gaps exist, report the gap and the smallest useful correction.
